# Japan Guide Bot 🌸

**Telegram-бот: гид по Японии на Python и aiogram.**

Бот присылает случайные факты о Японии, показывает текущую температуру в любом городе и делится фактами про кошек. Управление через кнопки под полем ввода, защита от спама встроена, данные берутся из публичных источников.

## Запуск

Склонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/GDKopat/Japan-Guide-TG-bot.git
cd Japan-Guide-TG-bot
pip install aiogram aiogram-sentinel python-dotenv requests
```

Получите токен у [@BotFather](https://t.me/BotFather) и создайте файл `.env` в папке `Japan bot`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
```

Затем запустите бота из этой же папки:

```bash
cd "Japan bot"
python main.py
```

Если токен найден, в консоли появится `Active ! ! !`, и бот начнёт отвечать в Telegram.

> [!IMPORTANT]
> Файл `.env` содержит секретный токен и уже добавлен в `.gitignore`. Никогда не публикуйте его в репозитории.

## Возможности

| Кнопка | Описание |
|--------|----------|
| **Fact⛩️** | Присылает случайный факт о Японии из текстового файла на GitHub |
| **Weather🌦️** | Просит название города и присылает текущую температуру через wttr.in |
| **Cat🐱** | Присылает случайный факт про кошек на русском языке из сервиса meowfacts |
| **Infoℹ️** | Показывает справку о возможностях бота |
| **Защита от спама** | Команда `/start` и справка не отвечают чаще, чем раз в 5 секунд; повторное нажатие факта, пока предыдущий запрос не завершён, игнорируется |
| **Обработка ошибок** | При проблемах с сетью бот отвечает понятным сообщением, а при неизвестном городе просит ввести название ещё раз |

## Технологии

| Область | Используется |
|---------|--------------|
| Язык | Python 3 |
| Фреймворк бота | aiogram 3 (роутеры, FSM, inline- и reply-клавиатуры) |
| Защита от спама | aiogram-sentinel (debounce) |
| HTTP | `requests` |
| Источники данных | wttr.in, meowfacts, GitHub Raw |
| Конфигурация | `python-dotenv` |

## Известные ограничения

- Файла `requirements.txt` пока нет, зависимости ставятся вручную.
- Для работы нужен интернет: все данные запрашиваются на лету.
- Факты о Японии хранятся в стороннем репозитории, поэтому бот зависит от его доступности.
- Запросы выполняются библиотекой `requests` синхронно, поэтому при медленном ответе источника бот может ненадолго зависнуть для всех пользователей.
- Состояния диалога хранятся в памяти, после перезапуска бота ожидание названия города сбрасывается.
- Название города нужно вводить так, как его понимает wttr.in, иначе бот ответит, что город не найден.
